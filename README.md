# Devendra Mulewa

Personal portfolio website for Devendra Mulewa, a software engineer based in India.

The site is intentionally simple: static HTML, CSS, and a small JavaScript file for work-item image previews. The home page also has a WebGL grass footer (three.js from a CDN) and a wind cursor. It includes a homepage, work, things, gems, and archive pages, SEO metadata, JSON-LD, a sitemap, robots.txt, and llms.txt.

Public site: https://devendram.com/
